# Framepixl

A lightweight, photo editor and framing studio built with  HTML, CSS, and JavaScript. Edit images directly in your browser with zero external libraries or server.
<img width="1917" height="902" alt="Screenshot 2026-11-15 194517" src="https://github.com/user-attachments/assets/8b35e886-4e0f-4dc9-95b9-553dd7361eae" />

## Features

- **Drag & Drop Loading** 
- **Real-Time Adjustments** 
- **Custom Framing**
- **Presets** 
- **PNG Export**

## procedure to run it locally

No build tools or package installations are required.

1. Clone or download this repository
2. Open `index.html` in any modern web browser.
3. Drop an image onto the canvas or click **Open Image** to begin editing.
